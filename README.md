# tabcurate

> CAUC 理学院竞赛用 · 智能表格整理 AI Skill

`tabcurate` 是一个**纯流程型 AI Skill**，用于整理多人填写的线上表格。它本身不包含任何处理脚本，只告诉 AI「处理流程 + 判断规则」；AI 借助自身环境中的工具读取、判断并修改表格，最终产出格式统一、可直接用于统计的干净表格。

## 为什么需要它

竞赛报名、信息采集等场景常用在线协作表格（腾讯文档、飞书表格、石墨、Google Sheets、Excel Online 等）。表格回收后，多人填写导致格式不一致，人工整理耗时且易错：

| 痛点 | 例子 | tabcurate 的处理 |
| --- | --- | --- |
| 日期格式混乱 | `2024/1/5`、`2024年1月5日`、`01/02/2024` 混用 | 有例子行则照例子行统一，否则 `YYYY-MM-DD`；歧义时让用户确认 |
| 长数字串变科学计数法 | 学号 `2.02301E+17` | 区分「标识符」与「合法数值」；恢复格式，**精度丢失时明确警告** |
| 下拉列被手动输入 | `男` / `Male` / `M` / `男生` | 按表格配置的选项集做语义对齐，拿不准就问用户 |
| 首尾有非预期格式符 | 前后空格、零宽字符、全角空格、前导 `'` | 只清首尾，不动内部 |
| 改动不可追溯 | 不知道哪里被改了 | 输出逐单元格变更报告与待确认清单 |

核心原则：**最小改动、不破坏语义、可逆可审计、无法确定交给用户**。

## 工作方式

1. 读取表格，推断每列类型（`date` / `id` / `number` / `choice` / `text`）。
2. 按列确定规则：日期格式（例子行优先，否则 ISO）、选项集（仅取自表格自身配置）。
3. 逐单元格检测异常，按置信度分级处理：

   | 策略 | 含义 |
   | --- | --- |
   | `auto` | 高置信度，直接修复 |
   | `review` | 有首选但不确定，汇总后一次性请用户确认 |
   | `report` | 无法判断，不修改，仅提示 |

4. 另存副本（原文件不动），输出干净表格 + 变更报告 + 待确认清单。

完整流程与判断规则见 [`SKILL.md`](SKILL.md)，设计说明见 [`docs/DESIGN.md`](docs/DESIGN.md)。

## 安装与使用

### 1. 安装 Skill

把仓库中的 `SKILL.md` 放到你所用 AI 工具的 skills 目录。常见方式：

- **Claude Code（项目级）**：将 `SKILL.md` 复制为 `.claude/skills/tabcurate/SKILL.md`；个人全局则放到 `~/.claude/skills/tabcurate/SKILL.md`。
- **OpenCode**：放到项目的 `.opencode/skills/tabcurate/SKILL.md`（或对应的全局 skills 目录）。
- **Cursor / 其他 Agent**：按工具约定放入 skills/rules 目录；若工具不支持自动加载，可直接把 `SKILL.md` 内容作为上下文提供给 AI。

> Skill 不绑定具体工具或表格库。AI 会根据输入文件格式，自行选择可用的工具完成读写与判断。

### 2. 调用

在对话中提供表格文件，并说明要整理即可。例如：

> 帮我整理这份回收的报名表 `报名信息.xlsx`，把日期、学号和性别列统一一下。

> 这份 `data.csv` 是多人填的，格式很乱，按 tabcurate 的流程清洗一下。

AI 会按 `SKILL.md` 的流程处理；遇到需要你决策的地方（日期顺序、选项语义、精度风险等），会**汇总成一次提问**，不会逐个打断。

### 3. 支持的格式

`xlsx` / `xlsm`、`xls`、`csv` / `tsv`（自动识别 GBK / UTF-8 / UTF-8-BOM）、`ods`，以及腾讯文档 / 飞书 / 石墨 / Google Sheets 等在线表格导出的上述格式。

## 输出物

每次运行产出：

1. **整理后的文件**：`*_cleaned.<原扩展名>`，原文件保持不变。
2. **变更报告**：逐条 `位置 | 原值 | 新值 | 规则 | 置信度 | 策略 | 说明` + 汇总统计。
3. **待确认清单**：集中列出所有需要用户决策的项。

回复与报告使用**用户期望的语言**，由调用 AI 自行判断。

## 注意事项

- **绝不覆盖原始文件**：始终另存副本。
- **精度红线**：长数字被 Excel 存成 double 后，科学计数法显示时精度通常不可逆丢失。Skill 只恢复格式，**不声称恢复原值**，精度可疑时会明确提示回原始来源核对。
- **不动公式**：默认不修改含公式的单元格。
- **幂等**：同一表格处理两次，第二次不产生新改动。
